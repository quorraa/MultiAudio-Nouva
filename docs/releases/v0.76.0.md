# MultiAudio Nouva v0.76.0 — Astra

Astra is now the default interface, with a listening-room view, mixing console, persistent transport, and direct output controls. Historical v1/v2/v3 and experimental interfaces remain available under Legacy; their original URLs still work.

- Adjust output count, volume, mute, solo, and delay from the control surface. Remove outputs while playback is stopped.
- Use fixed speaker-specific sync clicks: output 1 low, 2 mid, 3 high, 4 bright, with a stronger first beat every four seconds. Compare two speakers and add delay to the click heard first.
- Toggle acoustic auto-sync noise independently of the manual tick; disabling markers clears queued marker audio.
- Preserve small output configurations, serialize atomic configuration saves, reject duplicate output assignments before mutation, and guard browser control requests against cross-origin access.

## Download and run

Download and extract `MultiAudioNouva-0.76.0-win-x64-portable.zip`, then run `MultiAudioNouva.exe` from the extracted folder. Keep `wwwroot` alongside the executable. This is a self-contained Windows x64 build; no separate .NET installation is required.

## Validation

Release-mode audio/control regression tests and visualizer tests passed. The extracted portable ZIP passed API and Astra/legacy route smoke tests, plus a muted stereo virtual-device test of the four-beat clock and tick toggling. Acoustic alignment still depends on the speakers and listening position; the visual beat indicates source timing.
